# Aktaklik Funnel Showcase

Showcase statis untuk 3 funnel iklan Aktaklik: iklan Instagram, landing page, popup form 2 langkah, video cara kerja, dan jadwal konsultasi 15 menit.

- `index.html`: 3 iklan dalam mockup HP
- `lp-1.html`, `lp-2.html`, `lp-3.html`: landing page tiap funnel
- `video.html`: video cara kerja (4 part)
- `jadwal.html`: pilih jadwal konsultasi

Tanpa build step. Buka `index.html` langsung, atau deploy sebagai static site.
Nomor WhatsApp tim diatur di `WA_NUMBER` pada `assets/app.js`.
